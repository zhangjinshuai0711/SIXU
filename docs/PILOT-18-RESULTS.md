# 思序：六题、18 次首答实验结果

记录整理日期：2026-11-09。结果来自使用者提交的完整首次回答及事后离线评分。
本页仅公开题号、汇总和方法，不包含私人聊天原文、运行 ID 或连接地址。

## 测试方法

六道项目自编题，每题各一次：

- A：Instant 直接回答，不使用工具。
- B：Instant 按候选、约束与反例提示自查，不使用工具。
- C：Instant 使用思序自适应流程，不使用其他工具或模型。

题面在各组保持一致，按预先安排的六种组别顺序在新聊天中测试。用户提供回复；
无法独立确认每次模型身份、实际使用的工具、完整端到端耗时或生成量。成绩是
最终 JSON 的客观评分：Python 题执行固定程序比对；优化题检查约束与声明值，
并穷举最优解。验证在同题三份首答收齐后进行，不向测试模型反馈。自然语言解释
另行审查，不因 JSON 正确就认定证明完整。

前 9 次使用本地 v0.2.1 流程；出现 C 组调用失败后暂停。后 9 次作为另一批
使用云端 v0.3.1 进行，历史提示中的 `pilot-v021` 是保留的客户端标签，
不是版本认证。两批环境和版本不同，不应当作为单一固定条件的 18 次实验汇总。

## 修复后的重试

此前三道 C 组题目在迁移后单独重试，三份最终 JSON 均正确且回答报告工作流完成。
这些题目及答案已经暴露，服务器轨迹没有在记录会话独立核验；重试只提供有限的
连接回归观察，不替换第一批首答，也不作为未见题效果数据。

## 可以与不能得出的结论

这次观察到：思序可以保存并推进结构化流程；第一批有一次由本地记录支持的
错误候选修订；第二批项目选择题中 B、C 答对而 A 没有达到最优。但第二批班次题
三组均答对，且三份说明均不够完整；第一批也有工具失败和错误答案。

因此，这些结果**尚不能证明思序总体或稳定地优于直接回答或强化提示**。题目少、
每种条件仅一次、版本和环境中途改变、部分组别冲突、缺少生成量与耗时匹配，
也无法将模型自查、生成量和调度机制的作用分开。`completed` 只表示协议流程
完成；服务不独立执行通用答案的语义验证。下一步需要冻结版本和题集，使用新题、
多次重复及统一计时，并记录实际工具调用与证明质量。
