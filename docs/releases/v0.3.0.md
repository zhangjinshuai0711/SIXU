# 思序 · Reasoning v0.3.0

私有云端部署版本。将原先依赖本机临时通道的 MCP 流程迁移到固定云端入口，
保留线性与自适应推理协议、逻辑预算和候选修订规则。

- 新增 Sites 私有身份网关、按用户隔离的 D1 状态持久化与并发更新保护。
- 两种流程均可跨请求恢复状态，任务访问期限为创建后两小时。
- 保留本地部署，增加实际连接健康检查与 `doctor` 诊断。
- 保留用户提供的目标架构图、历史版本及原始实验失败记录。
- 不增加模型调用或付费 API。

32 项本地检查及云端构建通过。真实聊天非实验题完成五次提交并到达 `completed`，
随后由云端状态工具读取确认；验证支持基础连接与工作流可用。

VPN 切换专项验证、自适应流程的真实云端回归和修复后 C 组重试尚未完成。
本次不是推理效果对照实验，不能据此宣称正确率提升；`completed` 只表示协议完成。
过期记录在用户开始新任务时清理，不承诺两小时后精确物理删除。

当前托管实例仅限所有者使用；公开源码不附带云端访问权限。
